Connecting Live PayPal SDK

3-step developer guide for your website.

Step 1: Get Your PayPal Client ID

Log in to developer.paypal.com, go to Apps & Credentials, create a REST API App, and copy your Client ID.

Step 2: Add PayPal JS SDK to HTML Head

Paste this script inside your <head> tag (replace YOUR_CLIENT_ID):

<script src="https://www.paypal.com/sdk/js?client-id=YOUR_CLIENT_ID¤cy=USD"></script>

Step 3: Render PayPal Smart Buttons

paypal.Buttons({
  createOrder: (data, actions) => {
    return actions.order.create({
      purchase_units: [{ amount: { value: '49.00' } }]
    });
  },
  onApprove: (data, actions) => {
    return actions.order.capture().then(details => {
      alert('Subscription Activated for ' + details.payer.name.given_name);
    });
  }
}).render('#paypal-button-container');
